# OASIS Android Task 3 - Calculator App

## Objective
Build a clean, fully functional Android calculator app that handles basic arithmetic operations with a responsive button grid interface.

## Tools Used
- Android Studio
- Java
- XML
- GridLayout

## Features
- Number buttons (0–9) and decimal point
- Operators: +, −, ×, ÷
- Equals (=) and Clear (C) buttons
- Backspace functionality
- Division-by-zero error handling
- Responsive button grid layout
- No crashes on rapid/repeated button taps

## Steps Performed
1. Created a new Android Studio project with Empty Views Activity (Java)
2. Designed the calculator UI using GridLayout in activity_main.xml
3. Implemented calculator logic in MainActivity.java including number input, operator handling, and result calculation
4. Added error handling for division by zero
5. Tested the app on Android emulator (Pixel 6, API 34)

## Outcome
A fully working calculator app that performs addition, subtraction, multiplication, and division accurately, with proper error handling and no crashes.
